# 成人糖尿病食养助手 (Diabetes Food Guide Skill)

基于国家卫生健康委《成人糖尿病食养指南（2023年版）》的AI科普对话助手。

## 概览

| 项目 | 内容 |
|------|------|
| 指南全称 | 成人糖尿病食养指南（2023年版） |
| 发布机构 | 国家卫生健康委 |
| 版本 | v1.0.0 |
| 作者 | 王润圆 |
| KPK数量 | 14条（KPK-01~14） |
| 食谱数量 | 84套（7地区×4季节×3套） |
| 中医证型 | 3型（阴虚热盛、气阴两虚、阴阳两虚） |
| 食养方 | 9个 |
| 交换表 | 7类 |

## KPK知识体系

### 食养原则（KPK-01~08）

| KPK | 标题 |
|-----|------|
| KPK-01 | 食物多样，养成和建立合理膳食习惯 |
| KPK-02 | 能量适宜，控制超重肥胖和预防消瘦 |
| KPK-03 | 主食定量，优选全谷物和低血糖生成指数食物 |
| KPK-04 | 积极运动，改善体质和胰岛素敏感性 |
| KPK-05 | 清淡饮食，限制饮酒，预防和延缓并发症 |
| KPK-06 | 食养有道，合理选择应用食药物质 |
| KPK-07 | 规律进餐，合理加餐，促进餐后血糖稳定 |
| KPK-08 | 自我管理，定期营养咨询，提高血糖控制能力 |

### 附录知识（KPK-09~12）

| KPK | 标题 |
|-----|------|
| KPK-09 | 附录1：成人糖尿病患者的食物选择（GI分类表+证型食药物质推荐） |
| KPK-10 | 附录2：常见食物交换表（7类交换表，每份约90kcal） |
| KPK-11 | 附录4：食养方举例（9个中医食养方） |
| KPK-12 | 附录5：糖尿病诊断标准（WHO 1999 + HbA1c标准） |

### 疾病背景与问答（KPK-13~14）

| KPK | 标题 |
|-----|------|
| KPK-13 | 疾病背景（流行病学+WHO分类+中医辨证分型） |
| KPK-14 | 问答整合（6大模块：适用人群/膳食核心/中医食养/三餐安排/低血糖预防/禁忌提醒） |

## 中医证型

| 证型 | 关键症状 | 食养方向 |
|------|----------|----------|
| 阴虚热盛 | 烦渴多饮，咽干舌燥，多食善饥，溲赤便秘 | 清热滋阴 |
